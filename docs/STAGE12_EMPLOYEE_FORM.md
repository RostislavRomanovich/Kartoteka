# Этап 12 — создание и редактирование карточки сотрудника

## Возможности интерфейса

- Кнопка создания карточки доступна ролям `admin` и `editor`.
- В существующей карточке отображается действие редактирования для этих же ролей.
- Форма сгруппирована по разделам: основные сведения, служба и подразделение, допуск, контракт, воинский учёт.
- Обязательны фамилия и имя; ограничения длины полей соответствуют серверному DTO.
- Даты вводятся в формате `ДД.ММ.ГГГГ`; клиент проверяет формат и реальную календарную дату, затем преобразует значение в ISO `ГГГГ-ММ-ДД` для API.
- Срок контракта проверяется как целое число от 1 до 600 месяцев; проверяется порядок дат контракта и дата рождения.
- Создание выполняется `POST /api/employees`, изменение — `PUT /api/employees/{id}`.
- Во время сохранения повторная отправка блокируется; ошибки сервера отображаются в форме. Ошибка уникальности табельного номера от сервера не скрывается.
- После успешного сохранения список и уведомления обновляются; при редактировании повторно открывается карточка сотрудника.

## Безопасность и защита от дубликатов

Скрытие кнопок в браузере — только удобство интерфейса, не механизм безопасности. Серверный `EmployeesController` продолжает требовать политику `CanEditEmployees`. Уникальность табельного номера проверяется сервером и ограничением базы данных, поэтому две параллельные попытки не должны полагаться только на клиентскую проверку.

ФИО не используется как уникальный ключ. Совпадающие ФИО допустимы.

## Проверки

Запустить из каталога проекта:

```powershell
python tests/check_stage12_employee_form.py
python tests/check_stage11_ui.py
node --check wwwroot/app.js
```

Это статические проверки HTML/JS/CSS и структуры кода. Они не заменяют сборку `dotnet build`, миграции PostgreSQL, API-интеграционные тесты и ручную проверку браузера.

## Известные ограничения

- В этой форме пока доступны основные поля сотрудника, но не редактирование всех связанных сущностей (родственники, транспорт, награды и т. п.).
- Подразделение на этом этапе вводится текстом в поле `subdivision`; выбор из иерархического справочника подразделений предстоит добавить отдельно.
- Строгое форматирование даты контролируется при сохранении; форма не пытается автоматически угадывать неоднозначные даты.
- Компиляция C# и работа с реальным PostgreSQL в текущей среде не проверены.
