# Этап 16 — журнал действий и требования к установке

## 1. Журнал действий

Добавлен административный endpoint `GET /api/admin/audit`. Он доступен только роли `admin` и поддерживает поиск по пользователю, действию, типу/идентификатору объекта и деталям, постраничную выдачу (до 200 записей на страницу) и необязательные фильтры `fromUtc` / `toUtc`.

В интерфейсе для администратора появилась кнопка «История действий». Таблица показывает время, пользователя, действие, объект, дополнительные сведения и IP-адрес, если он был доступен. Обычные редакторы и читатели не видят кнопку, а API независимо проверяет роль на сервере.

Журнал не является системой хранения снимков всех прежних значений: существующие контроллеры фиксируют разные события, но аудит не гарантирует подробное сравнение «до/после» для каждого поля. В следующих этапах нужно централизовать аудит изменения данных, включить экспорт и расширить тестирование. Не записывать пароли, токены, содержимое документов и значения чувствительных персональных полей в `Details`.

## 2. Обязательные требования к итоговой поставке

Цель — один установочный файл Windows, запускаемый пользователем без знаний о .NET, PostgreSQL, службах Windows или командной строке. Установщик должен сам выполнить предварительные проверки, разместить компоненты, настроить службу сервера, создать ярлык и выполнить проверку готовности. Нельзя считать установщик готовым, пока эти действия не реализованы и не проверены на чистой Windows-машине.

### Предлагаемая схема для организации с несколькими пользователями

- Один `Kartoteka-Setup.exe` содержит клиент, опубликованный сервер, необходимые runtime-компоненты и проверенный дистрибутив PostgreSQL либо другой согласованный способ его установки.
- На выбранном постоянно работающем компьютере выполняется установка серверной части и базы данных. Мастер предлагает выбрать каталог данных и проверить свободное место; каталог данных не должен располагаться внутри каталога обновляемой программы.
- Установщик генерирует уникальные секреты, сохраняет их с ограниченными правами доступа и создаёт первого администратора через мастер. Никаких общих паролей по умолчанию в дистрибутиве быть не должно.
- Сервер запускается как служба Windows с автоматическим восстановлением после перезапуска. Интерфейс открывается ярлыком; клиентские компьютеры подключаются к серверу в локальной сети по согласованному адресу.
- Сетевая настройка ограничивается необходимым портом и профилем частной сети. TLS-сертификат и доверие к нему должны быть настроены предсказуемо, без отключения проверки сертификатов.
- Установка и обновление не должны удалять или перезаписывать каталог базы данных и вложений. Перед обновлением выполняется резервная копия, проверяется её завершение, затем запускаются миграции схемы с понятным отчётом.
- Должны быть мастер первоначальной установки, режим обновления, удаление приложения с явным отдельным выбором судьбы данных, журнал установки и диагностический экран без раскрытия секретов.
- Предусмотреть плановое резервное копирование, проверку возможности восстановления, контроль свободного места и понятное сообщение при недоступности сервера.

### Что означает «один установочный файл»

Один файл — это способ доставки компонентов, а не требование, чтобы все сотрудники работали с одной локальной копией базы. Для совместной работы более одного сотрудника нужна единая серверная база, доступная по сети. Практичный вариант — один раз установить серверную часть на выделенный/постоянно работающий компьютер, а остальные рабочие места подключить к нему. В будущем можно сделать отдельный облегчённый клиентский установщик, но основной поставляемый пакет всё равно может быть единым.

## 3. Текущие ограничения

На этапе 16 добавлен журнал в интерфейсе и административный API. Полноценный Windows-установщик, автоматическая установка PostgreSQL, настройка службы Windows, создание первичного администратора через графический мастер, обновление без потери данных и восстановление из резервной копии ещё не реализованы. До этого момента пакет является исходным проектом для разработки, а не готовым установщиком для конечных пользователей.
